================================================================
คู่มือการอัปโหลดระบบขึ้น Host จริง (Production Deploy Guide)
================================================================

ไฟล์นี้อธิบายขั้นตอนการย้ายระบบจาก localhost (MAMP) ขึ้น host จริง

----------------------------------------------------------------
ขั้นตอนที่ 1: เตรียมไฟล์ก่อนอัปโหลด
----------------------------------------------------------------

1. ลบไฟล์และโฟลเดอร์ที่ไม่จำเป็นออกก่อนอัปโหลด:
   - phpinfo.php
   - setup_main.php.backup
   - โฟลเดอร์ .git/ (หรืออย่างน้อยให้ใส่ใน .gitignore)
   - โฟลเดอร์ mail_log/ (ถ้าไม่ต้องการเก็บ log เก่า)
   - โฟลเดอร์ db/backup/ (ไฟล์สำรองฐานข้อมูลเก่า)
   - ไฟล์ .DS_Store ทั้งหมด

2. ตรวจสอบไฟล์ต่อไปนี้ว่ามีอยู่ครบถ้วน:
   - .env_real          <-- แก้ไขค่าให้ตรงกับ host จริงก่อนอัปโหลด
   - .htaccess_real     <-- สำหรับ production (เปลี่ยนชื่อเป็น .htaccess บน host)
   - db.php             <-- รองรับทั้ง development และ production แล้ว
   - mail_helper.php    <-- ถูกบล็อกไม่ให้เข้าถึงผ่าน URL แล้ว

----------------------------------------------------------------
ขั้นตอนที่ 2: แก้ไขไฟล์ .env_real ให้ตรงกับ host จริง
----------------------------------------------------------------

เปิดไฟล์ .env_real แก้ไขค่าต่อไปนี้:

   APP_ENV=production
   DB_HOST=localhost              (หรือ IP ของ database server ของ host)
   DB_PORT=3306
   DB_DATABASE=ชื่อฐานข้อมูลจริง
   DB_USERNAME=ชื่อผู้ใช้ฐานข้อมูลจริง
   DB_PASSWORD=รหัสผ่านฐานข้อมูลจริง
   MAIL_DRIVER=smtp
   MAIL_HOST=smtp-relay.brevo.com
   MAIL_PORT=587
   MAIL_ENCRYPTION=tls
   MAIL_USER=อีเมลของคุณ@domain.com
   MAIL_PASS=รหัสผ่านหรือ App Password
   MAIL_FROM=อีเมลของคุณ@domain.com
   MAIL_FROM_NAME=Thepha Care
   APP_DEBUG=false

----------------------------------------------------------------
ขั้นตอนที่ 3: เปลี่ยนชื่อไฟล์บน host จริง
----------------------------------------------------------------

เมื่ออัปโหลดไฟล์ขึ้น host ให้เปลี่ยนชื่อดังนี้:

   .env_real      →  .env
   .htaccess_real →  .htaccess

----------------------------------------------------------------
ขั้นตอนที่ 4: ตั้งค่าสิทธิ์ไฟล์ (File Permissions)
----------------------------------------------------------------

บน host จริง ให้ตั้งค่าสิทธิ์ไฟล์ดังนี้:

   .env           →  600 หรือ 640 (ห้ามเป็น 644 เพื่อป้องกันการอ่านจากเว็บ)
   .htaccess      →  644
   โฟลเดอร์ต่างๆ →  755
   ไฟล์ PHP       →  644

----------------------------------------------------------------
ขั้นตอนที่ 5: สร้างฐานข้อมูลบน host จริง
----------------------------------------------------------------

1. เข้าไปที่ phpMyAdmin หรือ MySQL ของ host จริง
2. สร้างฐานข้อมูลใหม่ (เช่น ชื่อเดียวกับ DB_DATABASE ใน .env)
3. นำเข้าไฟล์โครงสร้างฐานข้อมูล:
   - db/smi_schema.sql
   - db/smi_patient_group_schema.sql
   - pages/imp/migrations/2026_10_22_create_import_tables.sql

----------------------------------------------------------------
ขั้นตอนที่ 6: ทดสอบระบบบน host จริง
----------------------------------------------------------------

หลังอัปโหลดและเปลี่ยนชื่อไฟล์แล้ว ให้ทดสอบดังนี้:

1. เปิดเว็บไซต์: https://domain-of-you.com/
2. ทดสอบเข้าสู่ระบบที่ /login.php
3. ทดสอบฟังก์ชันหลัก เช่น สมัครสมาชิก, รีเซ็ตรหัสผ่าน
4. ตรวจสอบว่าไม่มี error เกี่ยวกับการเชื่อมต่อฐานข้อมูล
5. ตรวจสอบว่าการเข้าถึง .env ผ่าน URL ถูกบล็อก (ต้องขึ้น 403 Forbidden)

----------------------------------------------------------------
ขั้นตอนที่ 7: เมื่อใช้งานจริงแล้ว
----------------------------------------------------------------

1. เปลี่ยน APP_DEBUG เป็น false ใน .env (ถ้ายังไม่ได้ตั้งไว้)
2. ตรวจสอบว่าอีเมลส่งถึงผู้ใช้จริงหรือไม่ (หากใช้ MAIL_DRIVER=smtp)
3. สำรองข้อมูลฐานข้อมูลเป็นประจำ

================================================================
หมายเหตุสำคัญ
================================================================

- ไฟล์ PHP ทุกไฟล์ในระบบรองรับทั้ง development และ production
  อยู่แล้วผ่านการอ่านค่า APP_ENV จากไฟล์ .env
- จึงไม่จำเป็นต้องสร้างไฟล์ PHP แยกสำหรับ production
- ไฟล์ที่ต้องแก้ไขจริงๆ มีเพียง .env (หรือ .env_real เมื่อเปลี่ยนชื่อ)
- หากพบข้อผิดพลาด ให้ตรวจสอบ error log ของ host หรือตั้ง
  APP_DEBUG ชั่วคราวเพื่อดูรายละเอียด error
